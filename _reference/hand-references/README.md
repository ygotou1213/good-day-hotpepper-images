# モデル本人の手の参考画像

確定リファレンスセット（`_reference/ref-A〜D`）から、モデル本人の手の部分だけを切り出したもの。
手・指・爪は識別スペックの［最重要］項目（設計書「人物（AIキャラクター）の一貫性方針」）。
手が写る画像（①③）を生成する時は、ポーズや構図の参考とは別に、必ずこのフォルダの画像を
「手の形の正本」として添付する。外部の写真の手を手の形の手本にしない（2026-10-31、外部写真の手は
モデルの手と形が違い美しくないとユーザー指摘）。
